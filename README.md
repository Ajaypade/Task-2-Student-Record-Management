# Task-2-Student-Record-Management

Manages student records using Java in a console-based application.
Divided into three classes: Student, StudentManager, and Main.
Student class stores id, name, marks with getters/setters and toString().
StudentManager handles CRUD operations on an ArrayList<Student>.
addStudent() adds a new student from user input.
viewStudents() displays all students or shows “no records” if empty.
updateStudent() modifies name and marks for a given student ID.
deleteStudent() removes a student by ID or shows “not found”.
Main class shows a menu loop for user choices and calls manager methods.
Implements OOP concepts, interactive UI, and clear success/error messages.
